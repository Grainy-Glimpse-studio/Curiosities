# Speech Recognition — HD Mode

**HD Mode** uses Deepgram for higher accuracy transcription. This is not a sponsorship or affiliate link — I use it because it works well.

Deepgram offers $200 in free credits upon sign-up, which is approximately 770 hours of transcription. For most users, this will never run out.

Your API key is stored locally in your browser and never leaves your device. Neither I nor anyone else can access it. It will persist across page refreshes, but will be lost if you clear your browser cache, switch to a different browser, or use a different device.
